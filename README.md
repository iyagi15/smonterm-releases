# SMONTerm

여러 서버에 동시에 접속해서 쓰는 가벼운 Windows용 SSH 터미널입니다.
이 저장소에는 배포용 실행 파일만 올라옵니다.

## 설치

1. [Releases](../../releases/latest) 에서 `smonterm.exe` 를 받습니다.
2. 원하는 폴더에 두고 실행합니다. 설치 과정은 없습니다.
   - Windows 11 에는 필요한 구성요소(WebView2)가 기본으로 들어 있습니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행** 을 누르세요.

## 업데이트

새 버전이 나오면 프로그램 오른쪽 위에 `⬆ 새 버전` 버튼이 나타납니다.
누르면 자동으로 받아서 교체하고 다시 실행합니다. 받은 파일은 SHA-256 으로 검증합니다.
보안 프로그램이 새 실행 파일을 막으면 안내가 나오며, 프로그램을 직접 다시 실행하면 됩니다.

설정(⚙) 창 아래에서 현재 버전 확인과 업데이트 확인을 할 수 있습니다.

## 데이터

서버 목록과 설정은 각자 PC의 `%APPDATA%\smonterm` 에만 저장됩니다.
비밀번호는 Windows 계정 단위로 암호화(DPAPI)되어 다른 PC나 계정에서는 풀 수 없습니다.
